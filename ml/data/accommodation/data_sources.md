# Accommodation Data Sources

## Required Data

We need data for:
- Property information
- Location
- Accommodation type
- Capacity
- Rooms
- Amenities
- Pricing
- Hotel hourly pricing
- Availability
- Reviews
- Verification
- Accessibility
- Host information

## Data Source Categories

1. Open/public accommodation datasets
2. OpenStreetMap / location data
3. Public review datasets
4. Government/open tourism data
5. Our own Vistara demo/provider data

## Data Quality Rules

- Do not use private user data.
- Do not present synthetic/demo records as real properties.
- Record the source of each external dataset.
- Keep source and license information.
- Clean and standardize fields before ML use.
